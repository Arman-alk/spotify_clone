# 🎵 Spotify Clone

A simple Spotify Clone built using **HTML, CSS, and JavaScript**. This project recreates the basic user interface and music player functionality of Spotify.

## 🚀 Features

- 🎧 Play and pause songs
- ⏭️ Next and previous track controls
- 📊 Interactive progress bar
- 🎵 Song list with album covers
- 📱 Responsive user interface
- 🎨 Clean and modern design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/spotify-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
